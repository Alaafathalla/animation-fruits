# Jelly Garden | Three.js

A browser-based fruit playground with slicing, drag interactions and adjustable scene controls.

## Included interfaces

- Fruit interaction, slicing and geometry-cut modules.
- Physics, particle and scene controls.

## Built with

JavaScript, Three.js and Vite.

## Run locally

Install a Node.js version supported by the framework dependencies in `package.json`.

```bash
npm install
npm run dev
```

Open the local URL printed by the development server.

## Production build

```bash
npm run build
```
